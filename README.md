# Vercuiel Consulting Website

A full multi-page Next.js website for Vercuiel Business Consulting Services (Pty) Ltd.

## Pages
- Home
- Services (with separate Business Consulting, ERP Implementation and Business Automation pages)
- Websites & Pricing (R1,000 one-page; R3,000 multi-page; R5,000 interactive starter)
- Industries
- Selected Work
- About
- Contact

## Run locally
Install Node.js 20+, then run:

    npm install
    npm run dev

## Deploy
Connect this GitHub repository to the **vercuielconsulting** project in Vercel. Use Next.js framework, root directory of the repository, and production branch `main`. Vercel will build on commits automatically.

## Domain migration
The current www.vercuielconsulting.com website is hosted on Odoo. Do **not** change domain DNS until the new Vercel deployment is tested and the contact flow is configured. Keep email-related DNS records unchanged when migrating web traffic.
